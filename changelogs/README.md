# Changelogs

Dieser Ordner enthält alle Changelogs für einzelne Tickets und Features.

## Struktur

Jede Changelog-Datei folgt dem Format:
- `changelog-YYYY-MM-DD-kurzbeschreibung.md`

## Format

Die Changelogs folgen dem [Keep a Changelog](https://keepachangelog.com/de/1.0.0/)-Format und dokumentieren:
- Hinzugefügte Features
- Geänderte Funktionalitäten
- Entfernte Features
- Technische Details (Commit-Hash, Autor, Datum)
